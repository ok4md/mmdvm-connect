mmdvm_connect 
--------------------------------------
Simple DMR network router that enables the connection of infrastructure elements within a DMR network (MMDVM or Hytera). It allows direct linking of hotspots, repeaters, or can be used for radio based linking without the need for an internet-based IP multisite network (radio linking of two or more neighboring repeaters. VHF link for UHF repeaters, UHF link for VHF repeaters.).

(DMR mode only)
