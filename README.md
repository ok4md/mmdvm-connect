mmdvm_connect 
--------------------------------------
Simple DMR network router that enables the connection of infrastructure elements within a DMR network (MMDVM or Hytera). It allows direct linking of hotspots, repeaters, or can be used for radio based linking without the need for an internet-based IP multisite network.

In the event of an internet connection failure,the application can also be used for radio linking of two or more neighboring repeaters. VHF link for UHF repeaters, UHF link for VHF repeaters.
UHF REPEATER 1 <---> mmdvm_connect <---> VHF Link
                                            |
                                            |
                                            V
UHF REPEATER 2 <---> mmdvm_connect <---> VHF Link


(DMR mode only)
