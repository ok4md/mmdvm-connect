mmdvm_connect 
--------------------------------------
Simple DMR network router that enables the connection of infrastructure elements within a DMR network (MMDVM or Hytera). It allows direct linking of hotspots and repeaters or can be used for radio-based linking without the need for an internet-based IP multisite network. This includes radio linking of two or more neighboring repeaters, such as a VHF link for UHF repeaters or a UHF link for VHF repeaters.

(DMR mode only)
